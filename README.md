# opencode-setup

Gjør maskinen klar for agentisk koding med OpenCode.

Verktøyet installerer ferdige **skills** (hjelpere) som lar OpenCode veilede deg steg for steg gjennom oppsett av GitHub, Jira, Figma og Piwik Pro.

```
npx opencode-setup
```

Start OpenCode på nytt etterpå, så er skillsene tilgjengelige.

## Skills som installeres

| Skill | Hva den gjør |
|-------|-------------|
| `onboarding` | Guider deg gjennom hele oppsettet, husker hvor du er |
| `install-mcp` | Kobler OpenCode til GitHub, Jira, Figma og/eller Piwik Pro |
| `github-setup` | Setter opp SSH-nøkkel, SSO og signerte commits |
| `figma-mcp` | Hjelper deg utforske Figma-design direkte i OpenCode |
| `piwik-analytics` | Kobler OpenCode til Piwik Pro for besøksstatistikk |
